# hatchit 🚀

A modern, Python project scaffolder combining the blazing speed of `uv` with the robust build ecosystem of `hatch`. 

`hatchit` generates publication-ready Python packages out-of-the-box, fully equipped with automated testing, documentation, and scientific publishing metadata.

## Quick Start

```bash
pip install hatchit
```
